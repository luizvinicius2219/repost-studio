REPOST STUDIO V0.3 - ATUALIZACAO COMPLETA DO FRONTEND

1) Salve este ZIP no seu computador (idealmente em Downloads).
2) Abra o PowerShell.
3) Execute:

cd C:\repost-studio\frontend
Expand-Archive -LiteralPath "$HOME\Downloads\Repost-Studio-V03.zip" -DestinationPath . -Force
npm run build

4) Se o build concluir com sucesso:

git status
git add src README_V03.md LEIA_PRIMEIRO.txt
git commit -m "Repost Studio v0.3 - scanner biblioteca e agendamento"
git push origin main

A Vercel fara o deploy da branch main.
