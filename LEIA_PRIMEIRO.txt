REPOST STUDIO V0.5

1. Extraia este ZIP em:
   C:\repost-studio\frontend

2. Substitua os arquivos quando o Windows perguntar.

3. Rode no PowerShell:
   cd C:\repost-studio\frontend
   npm run build

4. Se o build estiver aprovado, envie ao GitHub:
   git add .
   git commit -m "Repost Studio V0.5 - contas e agenda editorial"
   git push origin main

A V0.5 organiza contas, videos, dias, horarios, calendario e historico.
Ela ainda NAO publica automaticamente no TikTok.
